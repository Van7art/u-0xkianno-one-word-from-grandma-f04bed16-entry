> Contraption

## What this entry does

This entry sends exactly one word: the single word a grandma would text
about AI. `main.ts` writes that word — and nothing else — to
`/output/entry.txt`. No dependencies, no network, no randomness: the same
word on every run.

The word is **Contraption** — the word a grandma reaches for when she is
talking about a machine she does not fully understand. The most powerful
technology on earth, reduced by grandma to a fiddly device on the counter.

## How to run

```sh
node main.ts
```

Requires Node 22.18 or later. The program writes the word to
`/output/entry.txt` (creating the directory if needed) and exits.
